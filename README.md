🛡️ Phishing Awareness Training

A simple Python-based Phishing Awareness Training Quiz designed to help users identify phishing emails and understand common phishing indicators.

The program presents realistic-looking email examples and asks the user to classify each message as either Phishing (P) or Legitimate (L).

🎯 Project Objective

The goal of this project is to improve cybersecurity awareness by teaching users how to recognize suspicious emails, malicious links, urgent requests, and attempts to obtain sensitive information.

✨ Features

- 📧 5 email-based quiz questions
- 🔍 Identify emails as Phishing or Legitimate
- 💡 Explanation provided after every answer
- 📊 Final score and accuracy percentage
- 🛡️ Built-in phishing safety tips
- 🔐 Covers passwords, OTPs, suspicious links, urgency, and fake prizes
- 💻 Simple command-line interface
- 🐍 No external Python libraries required

🛠️ Technologies Used

- Python 3
- Python standard library

🎮 How to Use

When the program starts, it displays:

============================================================
          PHISHING AWARENESS TRAINING
============================================================

P = Phishing
L = Legitimate

For each email, enter:

- "P" → Phishing
- "L" → Legitimate

The program validates the input and shows whether your answer is correct, along with an explanation.

📊 Scoring System

After completing all questions, the program displays your score and accuracy.

Example:

============================================================

============================================================

Score: 4/5
Accuracy: 80.0%

The program provides different feedback depending on the final accuracy.

🔎 Phishing Indicators Covered

The quiz teaches users to look for indicators such as:

- Suspicious sender addresses
- Fake or misleading domains
- Urgent or threatening messages
- Requests for passwords or OTPs
- Suspicious links
- Unexpected prizes
- Requests for advance payments
- Requests for sensitive information

For example, one quiz question uses a suspicious PayPal-like domain and urgency to demonstrate phishing indicators.

🛡️ Safety Tips

The application provides the following security recommendations:

1. Check the sender's email address carefully.
2. Do not click suspicious links.
3. Never share passwords or OTPs.
4. Be careful with urgent or threatening messages.
5. Verify requests using official websites or phone numbers.
6. Do not pay unexpected fees to claim prizes.
7. Enable multi-factor authentication whenever possible.
